# Trimnexa — Multi-Vendor E-Commerce Marketplace

**A modern digital marketplace connecting buyers and sellers, initially focused on Cameroon.**

Trimnexa is a multi-vendor e-commerce platform designed to help businesses and individual sellers showcase products, manage their online presence, and connect with customers through a user-friendly shopping experience.

**Developed by:** Remy Bate Mbu  
**Project Type:** Full-Stack Web Application  
**Status:** Active Development  
**Source Code:** Private — Public Project Showcase

---

## 🚀 Project Overview

Trimnexa aims to simplify online buying and selling by bringing different vendors and customers together on one platform.

The application focuses on accessible marketplace functionality, organized product discovery, and a shopping experience adapted to regional markets.

## 🏗️ Technical Architecture

Trimnexa uses Next.js and React for its web application, with TypeScript for type safety.

Prisma ORM provides the database access layer, while MySQL supports relational data storage.

The project includes separate marketplace workflows for buyers, sellers, and product management.
